# Rick Cabugnason — Healthcare VA, Medical Billing & Operations Portfolio

A modern, responsive static portfolio showcasing 9+ years of experience across US medical billing, insurance verification, lab operations coordination, and branch management.

## Structure

- `index.html` — Main portfolio layout and semantic sections
- `styles.css` — Custom animations, navigation active states, and print/PDF styling
- `app.js` — Interactive experience filter, mobile menu, scroll-spy, and clipboard toast notifications
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment on push to `main`
